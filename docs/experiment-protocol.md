# 实验流程

以下为计划流程，尚未执行 M400 测绘或巡航实验。

## 1. 区域与测绘

选择一个固定实验区域，登记区域标识、WGS84/ENU 原点和垂直基准。记录 M400、测绘载荷、软件版本、定位模式和测绘航线。保留原始点云及处理配置，输出配准后的点云、地面模型和建筑分割结果。

每栋楼提取地面基底、二维轮廓和屋顶高度，生成简单挤出模型。真值楼高统计方式、点云密度、地面/屋顶过滤方式和误差估计随版本保存。抽查楼房轮廓与高程，使用控制点或独立测量核验配准。

## 2. 先验地图与基站

单独建立二维建筑先验，不包含真值楼高。若轮廓来自激光点云，将实验明确标为“激光辅助二维先验”；若来自独立二维地图，则另设地图版本与实验配置。

登记服务/邻区身份与基站位置。基站高度与建筑基底转换到同一 ENU 坐标，保留位置来源及不确定度。算法用的模型校准数据与最终评估航次分开记录。

## 3. 巡航与无线采集

同一区域进行可重复的巡航，记录航线配置、采样频率、高度层、速度、载荷/天线姿态和天气。包含水平巡航与垂直变化段，以获得不同几何约束。

机载采集器记录定位质量、时间同步情况和每次 AT 查询原始响应。生成结构化服务小区和邻区指标，按时间匹配三维位置。本机上传采用批次与持久化补传队列，保留原始机载日志用于核对接收记录。

## 4. 显示与回放

实时显示已接收的航迹、测量位置、无线指标和地图版本。回放读取固定航次的已保存观测，使用观测时间轴；比较实时与离线回放的记录数与结果一致性。

## 5. 论文重构与真值评估

以二维先验、基站坐标、RF 测量和 UAV 定位为算法输入。按论文实现路径损耗判决、几何高度约束及楼高后验，生成独立的 `rf_reconstruction` 地图。激光楼高只用于最终评估；如激光几何用于生成校准标签，登记其训练用途，并采用独立航次/空间划分评估。

评估按建筑对应关系输出：楼高 MAE/RMSE、绝对误差分位数、可估计建筑覆盖率、二维轮廓重叠度及简单挤出体的三维 IoU。额外记录随有效测量数量变化的误差曲线。未得到估计的建筑单独计数，避免只报告成功建筑。

对比至少包括仅先验估计与论文 RF 方法。更细高度区间、不同轨迹、测量数量、基站位置与定位误差作为独立扩展实验。固定输入数据版本、算法 Git 提交、参数、随机种子及评价口径，保存可重复运行的实验清单。
