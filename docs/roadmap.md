# 开发路线

项目按一个可运行的最小闭环逐步扩展。已完成项以实际代码为准，其余均为计划。

| 阶段 | 状态 | 交付物与验收 |
| --- | --- | --- |
| M0：初始化 | 已完成 | 公开仓库、背景与目标文档、本地空几何库、3 栋合成建筑；初始化/导入/查询/导出及数据完整性测试通过 |
| M1：激光几何真值 | 计划 | M400 + 测绘载荷取得区域点云；保存来源、坐标、精度和哈希；提取楼房轮廓、基底和楼高，导入独立 `lidar_truth` 地图 |
| M2：4G 采集闭环 | 计划 | 定位与 AT 采集适配器；时间匹配、原始日志、断网缓存、幂等补传；服务小区和任意邻区入本机数据库 |
| M3：显示与回放 | 计划 | 轻量网页显示楼房/轨迹/无线指标；增量更新；按航次、时间与小区筛选；暂停、倍速和时间跳转 |
| M4：按论文重构代码 | 计划 | 独立算法模块、论文公式对应说明、确定性合成测试；二维轮廓 + 基站 + RF 数据输入，输出楼高分布及地图版本 |
| M5：实飞与评估 | 计划 | 同一区域巡航、多高度采样、独立航次验证；与激光真值比较，输出楼高/几何误差与收敛曲线 |
| M6：开源复现包 | 计划 | 可发布数据、配置、运行脚本、版本与哈希；从干净环境完成示例和论文方法实验 |

## 论文算法重构范围

按 [*Prototype of Joint CKM and 3D Environment Reconstruction System via UAV RF Measurements*](papers/Prototype_of_Joint_CKM_and_3D_Environment_Reconstruction_System_via_UAV_RF_Measurements.pdf) 重新组织算法实现：

1. 式 (3)、(6)–(8)：每基站 LoS/NLoS 路径损耗模型、高斯似然与链路状态判决。
2. 式 (1)、(4)：二维建筑占据表示、视线相交和最低相交高度。
3. 式 (9)：LoS 观测更新建筑高度上界。
4. 式 (10)–(12)：NLoS 候选遮挡建筑、楼高区间概率更新及归一化。
5. 式 (5)、(13)–(15)：Rayleigh 先验、区间截断分布、多基站融合。
6. 后验期望与高度上界结合得到楼高估计，保存随有效测量变化的结果。

模块拆分为传播模型、链路判决、几何约束、楼高后验和运行/评估。先实现离线可复现版本，再接入增量实时处理。每次运行保存输入数据清单、配置、算法版本与随机种子；算法输入不读取 `lidar_truth` 高度。

首个论文复现配置采用论文中的 10 m 高度区间和 120 m 上限；更细分辨率作为独立扩展实验报告。M400 集成遵循同一数据约定，不把具体飞控接口耦合进算法核心。
